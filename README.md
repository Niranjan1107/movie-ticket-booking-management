# Movie Ticket Booking Management Application

## Overview

The Movie Ticket Booking Management Application is a Pega Platform application developed for CineWave Entertainment to manage movie ticket booking processes efficiently.

The application replaces manual booking and communication processes with a structured digital workflow.

## Project Objectives

- Allow customers to request movie ticket bookings
- Check movie show availability
- Calculate booking costs
- Capture customer confirmation
- Manage movie and show details
- Process ticket bookings
- Notify customers about booking confirmation
- Track booking status
- Define booking SLA
- Route booking requests based on show type
